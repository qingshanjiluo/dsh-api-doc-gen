# dsh-api-doc-gen

> DeepSeek Harness API 文档生成器插件

## 功能

- 📄 **OpenAPI/Swagger**: 自动生成 OpenAPI 3.0 规范文档
- 🔍 **路由扫描**: 自动发现 Express/FastAPI/Go 路由
- 📝 **Markdown 导出**: 生成可读的 Markdown API 文档
- 🔧 **类型提取**: 自动提取请求/响应类型

## 工具

| 工具名 | 说明 |
|--------|------|
| `api_doc_scan` | 扫描 API 端点 |
| `api_doc_generate` | 生成 OpenAPI 文档 |
| `api_doc_preview` | 预览文档 |
| `api_doc_export` | 导出到文件 |
